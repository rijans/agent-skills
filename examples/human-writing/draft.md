# Draft Example

## Brief

Write a short product description for a command-line tool that converts Markdown files to HTML. Keep it technical and understated.

## Example

`md2html` converts Markdown files to HTML from the command line.

It reads a local Markdown file and writes the generated HTML to a file or standard output. It is designed for simple build scripts and small documentation projects where a full publishing system would be unnecessary.

The description stays specific and does not invent benchmarks, user numbers, testimonials, or personal experience.
